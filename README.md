# 🔐 Encodify – Text Encryption & Decryption Platform

**Encodify** is a modern and user-friendly web application designed to encrypt and decrypt text using cryptographic techniques. It provides a simple, intuitive interface that allows users to transform plain text into encrypted ciphertext and convert it back into its original readable form.

Built with modern frontend technologies, Encodify focuses on simplicity, usability, responsive design, and secure text processing.

## ✨ Features

- 🔒 **Text Encryption:** Convert plain text into encrypted ciphertext.
- 🔓 **Text Decryption:** Restore encrypted text to its original readable format.
- 🛡️ **Cryptographic Algorithms:** Support for encryption algorithms such as AES and Caesar Cipher.
- 📋 **Copy to Clipboard:** Quickly copy encrypted or decrypted text.
- 🧹 **Clear Input:** Reset text fields with a single click.
- 📥 **Download Results:** Save encryption and decryption outputs.
- 🎨 **Modern UI:** Clean interface with attractive styling and smooth animations.
- 📱 **Responsive Design:** Works across desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Programming Language:** JavaScript
- **Cryptography:** Web Crypto API / CryptoJS
- **Icons:** Lucide React
- **Animations:** Framer Motion

## 🎯 Project Objective

The primary objective of Encodify is to demonstrate the practical implementation of text encryption and decryption techniques while developing an interactive and responsive web application.

## 🚀 Getting Started

1. Clone the repository.
2. Navigate to the project directory.
3. Install the dependencies using `npm install`.
4. Start the development server using `npm run dev`.
5. Open the local URL displayed in your terminal.
